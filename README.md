# Movie Recommendation System

A MovieLens 1M recommendation project combining collaborative filtering (SVD), content-based filtering (TF-IDF and cosine similarity), and hybrid recommendations. The Streamlit app accepts a MovieLens user ID and displays personalized movie suggestions.

## Project contents

- `app/`: Streamlit application
- `notebooks/`: exploratory analysis, preprocessing, model training, and evaluation
- `src/`: recommendation-related modules
- `requirements.txt`: Python dependencies

The MovieLens dataset, processed CSV files, and trained model files are intentionally excluded from this repository. Follow [SETUP.md](SETUP.md) to download the dataset and generate the artifacts needed to run the app.
